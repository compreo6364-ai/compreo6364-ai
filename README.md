## Research

**Knowledge attrition in open source software**

When a developer leaves a project, is what they knew carried on by the people who
remain, or is it lost? I work with public GitHub data, using survival analysis to
model what happens after a contributor's last commit.

What makes this interesting is that "carried on" and "lost" are not one outcome with
two labels. They are competing possibilities, and telling them apart changes what the
data is able to say.
